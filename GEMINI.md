# Anchor Project Guidelines

## Design Philosophy
- **Minimalism & Immersiveness**: One screen = one job.
- **No Visual Clutter**: Simple UI with only one primary action per screen.
- **Progressive Disclosure**: Simple by default, advanced detail only on tap.
- **Immersion**: Smooth motion/feedback, NOT extra UI elements.
- **Color Palette**: 3 colors max.
  - Background: `#0D0D0D` (Deep Black)
  - Text: `#F3F4F6` (Off-White)
  - Primary Accent: `#10B981` (Vibrant Emerald Green)

## V1 Must-Have Features
- **Today/Home Screen**: Unified daily view showing workout + food + net calories.
- **Log Workout Screen**: Quick entry (exercise, sets, reps, weight) + "repeat last session" shortcut.
- **Log Food Screen**: Quick entry (food name, calories, macros).
- **Plan Builder Screen**: Custom workout split definition + daily macro targets.

## Explicitly Out of Scope for V1
- Social features, feeds, or friend accountability
- Gamification badges/streak animations
- Wearable device sync
- AI chat coach
- Exercise video library
- Barcode/photo food scanning
